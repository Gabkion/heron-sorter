  1. If the Arduino is connected, click Disconnect first to free the serial port.
  2. Open sorter_sketch.ino on GitHub and copy all the code.
  3. Open the Arduino IDE, paste the code into a new sketch, and select your board (e.g. Arduino Leonardo) and port.
  4. Click Upload, wait for it to finish, then click Connect Arduino again.
